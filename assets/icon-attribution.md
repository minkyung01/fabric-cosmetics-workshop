# 아키텍처 아이콘 출처와 사용 조건

[목차](../README.md)

그림은 [Microsoft Fabric 공식 아이콘 안내](https://learn.microsoft.com/en-us/fabric/fundamentals/icons)에서 연결한 [microsoft/fabric-samples의 Icons.zip](https://github.com/microsoft/fabric-samples/blob/main/docs-samples/Icons.zip)에서 가져온 **v6.1.0** SVG를 사용합니다.

| 그림의 기능 | 파일 (`icons/`) |
|---|---|
| Lakehouse | `lakehouse_48_item.svg` |
| Ontology의 Fabric 플랫폼 표시 | `fabric_48_color.svg` |
| Graph model | `graph_model_instance_48_item.svg` |
| Data Agent | `data_agent_48_item.svg` |
| Notebook | `notebook_48_item.svg` |
| Eventhouse | `event_house_48_item.svg` |
| Operations Agent | `operations_agent_48_item.svg` |
| SQL database | `sql_database_48_item.svg` |
| Microsoft Purview | `purview_48_color.svg` |
| Microsoft Teams | `teams_48x1.svg` (아래 별도 출처) |

공식 컬렉션의 아이콘을 원본 그대로 포함하고 동일 비율로 표시했습니다. 자르기·회전·뒤집기·색상 변경을 하지 않았습니다. 다운로드한 컬렉션에 Ontology 전용 아이콘이 없어 해당 카드에는 **Fabric 플랫폼 아이콘**을 사용했으며, Ontology 전용 공식 아이콘이라고 주장하지 않습니다.

Microsoft는 아키텍처 다이어그램·교육 자료·문서에서의 아이콘 사용을 허용합니다. 상세 조건과 Do/Don't는 공식 안내를 확인합니다. 원본 패키지의 [LICENSE](icons/LICENSE)(Copyright © 2025 Microsoft Corporation)를 함께 보관합니다. 아이콘은 Microsoft 제품·항목을 나타내는 용도로만 사용하며 이 워크숍 자체의 로고로 사용하지 않습니다.

Teams SVG는 [Microsoft 공식 Office CDN](https://res.cdn.office.net/files/fabric-cdn-prod_20261014.001/assets/brand-icons/product/svg/teams_48x1.svg)에서 원본 그대로 가져왔습니다. CDN 버전은 [microsoft/fluentui의 공식 상수](https://github.com/microsoft/fluentui/blob/master/packages/style-utilities/src/cdn.ts)로 확인했습니다(2026-10-25). Fabric 아이콘 패키지의 MIT 라이선스가 Teams 자산에도 적용된다고 주장하지 않습니다. [Microsoft 365 아이콘 사용 조건](https://learn.microsoft.com/en-us/previous-versions/microsoft-365/solutions/architecture-icons-templates)의 문서·교육·아키텍처 용도로만 제품을 표시하며, Microsoft 상표·제품 식별 자산의 권리를 이전하는 것은 아닙니다.

아키텍처 편집·재생성 절차는 [관리자 가이드](../admin/README.md#로컬-점검키트-유지보수자용)에 있습니다.
